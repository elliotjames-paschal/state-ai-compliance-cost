Reuse factor

By default the model uses each family's own statute-derived reuse (shown next to each family in the cost chart); the global slider applies only when you override. Reuse = how much of the work for one state carries to the next, computed from the coded statute parameters: the share of parameters (age thresholds, notice timing, audit frequency) two states set to the same value, averaged across state pairs. Ops carryover sets how much of that reuse applies to recurring work — filings and audits repeat per state. Think it's wrong? Override with your own.

Method in brief

  • Bottom-up. Each law is coded into the duties it demands; each duty carries hour estimates for the average AI model. Cost is hours × rates — the same approach federal agencies use for regulatory burden estimates.
  • Increment, not total. The hypothetical federal standard is each family's least common denominator — the parameters every state sets identically, computed from the coded bills. That shared core is never claimed; only divergence beyond it is.
  • Reuse from statutes. Within a family, each additional state costs (1 − reuse) of a fresh build. Reuse is derived live from the coded parameters — the share two states set to the same value — never assigned.
  • Range, not point. 4,000 Monte Carlo draws over duty hours (seeded, so results are reproducible), with a shared estimation-error factor across bills so uncertainty doesn't wash out in the sum. The conservative end leads.

Every input is auditable: the coded dataset with quoted statutory sources ships in the repo (data/bills.js, full records in coding/). Feedback welcome — open an issue on anything that looks wrong.

Glossary duties, parameters, and how they fit together

How the model works, in five steps

  1. Every enacted state AI law was read and coded into four facts: who it binds (companies, individuals, agencies, or schools), which requirement family it belongs to, which duties it demands, and which parameters it sets — each anchored to a quoted provision.
  2. Duties drive cost. Each duty has hour estimates (legal review and engineering once; operations every year) for the average AI model. A law's cost is the sum of its duties' hours × your rates.
  3. Parameters drive discounts. Comparing two states' parameters gives reuse — the share of work that carries from one state to the next. What every state sets identically is the federal baseline — work a single national rule would have required anyway, so it is never counted.
  4. Each family is costed in sequence: the first state pays its divergence from the federal baseline; every later state pays (1 − reuse) of a fresh build, plus its share of recurring operations.
  5. The simulation runs 4,000 times with the hour estimates wiggled inside their ranges; the dashboard reports the resulting spread, conservative end first.

Parameters — the settings a law picks

Parameters are the concrete choices a statute makes — thresholds, deadlines, coverage. They never add cost directly; they measure how much states agree, which sets each family's reuse and federal baseline. Grouped by requirement family:

Chatbot safeguards — scope (which chatbots are covered) · ageFocus (minors or all users) · aiDisclosure (when the bot must say it's AI) · crisisProtocol · breakReminders · parentalTools · engagementLimits · contentSafeguards (each: required or not) · ageThreshold (who counts as a minor)
AI in mental-health practice — aiTherapyRule (ban / supervised / disclosure-only) · consentRequired · scope (psychotherapy or all clinical use)
AI in insurance decisions — humanReview (final decision or appeal) · decisionsCovered (denials / prior-auth / all) · disclosure · aiSoleBasis (AI alone may not decide) · appealDays
Automated decision governance — covers (developers / deployers / both) · trigger (which decisions count) · assessment (cadence) · consumerNotice · appealRight · optOut
Frontier model safety — threshold (compute / cost / capability) · safetyFramework · incidentReporting · thirdPartyAudit · whistleblower
Provenance & transparency — watermark · detectionTool · disclosureTrigger (what content is covered) · userThreshold (monthly users above which the duty applies)
Likeness & digital replicas — consentRequired · coveredSubjects (performers / everyone / deceased) · postmortemYears
Criminal prohibitions — prohibition (NCII / CSAM / election deepfakes / impersonation / suicide-encouragement) · coveredSubjects · electionWindowDays
Election AI disclosure — disclosure · scope (ads / robocalls / all communications) · windowDays (days before an election)
Algorithmic pricing & competition — prohibition (surveillance pricing / price coordination) · disclosure
Privacy & data (AI provisions) — admOptOut (opt out of automated decisions) · profilingAssessment · minorsFocus · registration
Workforce protections — retaliationProtection · noticeRequired
AI in clinical care — aiPracticeRule (ban / disclosure / supervision) · scope (licensure / treatment / all)
Licensed professions — aiRule (ban / disclosure / supervision) · profession
Government AI use — inventory (one-time / annual) · procurementRules · assessment · program
Schools & curriculum — curriculum · policyRequired · trainingRequired · graduationReq
Definitions only — no parameters; defines terms, imposes nothing
Data centers — scope (what infrastructure provision the law touches)
